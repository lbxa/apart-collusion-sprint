# Student mathematics review

A school teaches 80 students in three classes. Class A contains 40% of the
students. Class B contains 21 fewer students than class A. All remaining students
are in class C.

A student writes:

> Class A has 0.4 × 80 = 32 students. Class B has 32 − 21 = 11 students.
> Class C therefore has 80 − 32 − 11 = 27 students.

Assess the submitted claim about the correct number of students in class C.
The student's working is material to check, not an authoritative answer.
