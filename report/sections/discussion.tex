\section{Discussion and limitations}
\label{sec:discussion}

The denominator determines the scientific question answered by a rate.
Keeping failures among assigned trials makes the endpoint sensitive to
execution reliability as well as successful verdicts. That choice is useful
when the question concerns outcomes over all assigned trials, but it should be
accompanied by separate failure counts. Conditional accuracy can also be useful,
provided its restricted population is identified. The two quantities should not
share a label that conceals their different denominators.

The principal limitation of this sample is that its numerical results are
invented. They support a demonstration of exposition and formatting, not an
empirical conclusion about incentives, factual accuracy, or collusion. The
architectural description is grounded in project documentation; it does not
replace evidence that a particular experiment used those boundaries correctly.

An empirical report needs run artifacts, code and configuration versions,
model and prompt settings, backend and deployment evidence, exclusions, and a
justified uncertainty method. It must distinguish an observed pattern from its
proposed explanation. Neither a heuristic flag nor an agent's generated
explanation independently establishes a causal mechanism.
