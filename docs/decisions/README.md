# Decision records

Record consequential choices alongside the implementation. Use
[_template.md](_template.md), today's date, a descriptive filename without a
number, and people as deciders. Package facts belong in the nearest README
changelog; cross-package constraints and research choices belong here.

Records preserve the original rationale. Supersede an earlier choice with a new
record instead of rewriting its history. Mark an unverified rationale as
`NEEDS CONFIRMATION` and identify who can confirm it.

[INDEX.md](INDEX.md) is generated by `python3 scripts/decision-index.py`.
Do not edit it by hand. The verification gate checks that it is current.
